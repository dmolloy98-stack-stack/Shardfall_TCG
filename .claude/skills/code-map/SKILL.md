## docs/code-map.md

Update it whenever files are added, split or renamed, or the flow between them changes (CLAUDE.md
rule). Sections: the big picture, when you play a card, how a card gets its behaviour, how the
screens connect, **where to change things** (a table: "what you want to change" → files and
function names), size and shape. Plain English; function names only in the right column.

## Refreshing the archify pages

Both pages were generated by archify (generator tag `archify 3.2.0` in the page). To refresh:
`read` the page's url first (required before publishing to it from a new session), regenerate
it the same way it was made (ask the owner before installing archify again: `tool-check` rule
on downloads), check the new page lists the current files, and publish it to the same url with
no `icon`. If archify isn't available, say so and offer to update just `docs/code-map.md`.
Tell the owner both links when done. These pages are claude.ai only (private to the owner),
not part of the repo or the Drive backup.
